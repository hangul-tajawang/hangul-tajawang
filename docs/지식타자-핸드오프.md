## 1. 기능 개요 (원래 컨셉)

**"순서가 있는 지식을 지하철 노선처럼 한 역씩 타자로 정복하며 외운다."**

- 예: 조선 왕조 27대(태정태세문단세…). 각 왕 이름을 타자로 입력해 다음 "역"으로 이동하고,
  도착하면 공개되는 핵심 업적 한 줄까지 타이핑해야 출발.
- 니모닉 청크("태정태세문단세")를 노선도의 행 라벨로 사용.
- 진행 상태는 localStorage에 저장(중간 이탈 후 복귀 가능), 완주 시 타수(KPM) 기록.

## 3. 데이터 모델 (`lib/journey-data.ts`)

```ts
interface JourneyStation {
  id: string;
  name: string;        // 타이핑 대상(예: "태조")
  year?: string;       // 부가정보(예: "1392~1398")
  fact: string;        // 도착 시 타이핑할 핵심 지식 한 줄
  detail?: string;     // 추가 설명(표시용)
  hint?: string;       // 보조 힌트 — "주기율표 기호, 로마자 등 미래 코스용"(표시만, 타이핑 X)
  group?: string;      // 니모닉 그룹 id
}
interface JourneyLine { id: string; stations: JourneyStation[]; }
interface JourneyCourse {
  id: string;          // URL slug: /journey/[id]
  title: string;
  subtitle: string;
  description: string;
  category: '역사' | '지리' | '과학' | '상식';
  emoji: string;
  keywords: string[];  // 코스별 SEO
  groups?: { id: string; label: string }[];  // 니모닉 청크(노선도 행 라벨)
  lines: JourneyLine[]; // MVP는 1개, 멀티라인 대비 배열
}
```
- **코스 추가 = `JOURNEY_COURSES`에 객체 하나 추가가 전부.**
- `hint` 필드는 **주기율표 기호(H, He, Li…)를 위해 이미 예약됨** — 새 과학 코스 설계 시 활용.
- 헬퍼: `getJourneyCourse(id)`, `getCourseStations(course)`.

## 4. 새 방향 (사용자 지시)

1. **리브랜딩: "지식여정" → "지식타자"**
   - 컨셉: *"지식을 쌓으며 타자 실력을 높인다."*
   - 반영 위치: `Header.tsx`(라벨 2곳), `HomeClient.tsx`, `app/journey/page.tsx`(title/description/카피), `app/journey/[courseId]/page.tsx` 메타.
   - **결정 필요**: 라우트 slug을 `/journey` 그대로 둘지 `/knowledge`류로 바꿀지.
     권장 → **slug은 `/journey` 유지**(sitemap·내부링크·색인 깨짐 방지), **표시 텍스트만 "지식타자"로**. 굳이 바꾼다면 리다이렉트(`next.config` redirects) 필수.

2. **지하철 노선도 UI 제거**
   - `JourneyMap`(노선도 SVG)을 **공통 시각화에서 제거.** 이게 "지하철 노선도 빼기"의 핵심.
   - `JourneyPlay`가 `JourneyMap`을 하드코딩 중이므로, **시각화를 코스별로 교체 가능하게 리팩터**해야 함.

3. **코스별 컨셉 전용 UI**
   - 각 코스가 주제에 맞는 시각화를 갖도록. 권장 설계:
     - `JourneyCourse`에 `ui: 'map' | 'worldmap' | 'periodic'`(또는 유사) 필드 추가.
     - `JourneyPlay`에서 `course.ui`에 따라 시각화 컴포넌트를 선택(전략 패턴). 게임플레이 로직(입력·판정·진행저장)은 **시각화와 분리해 재사용**.

4. **코스 2종 추가**
   - **세계 수도**(category `'지리'`): 나라→수도 타이핑. UI 컨셉 = **세계지도/대륙별 그룹**(대륙을 `groups`로). 각 역 = 나라, `name`=수도 또는 나라(설계 결정), `fact`=수도/특징.
   - **주기율표**(category `'과학'`): 원소 타이핑. UI 컨셉 = **주기율표 그리드**. `hint`에 원소기호(H, He…), `name`에 원소명, `group`에 족/주기. 예약된 `hint` 필드 활용.

## 6. 주의사항 / 열린 결정

- **커밋 위생**: 다른 에이전트와 파일이 겹치지 않게, 본인이 만진 파일만 `git add`.
- **slug 변경 여부**(4-1) — 사용자 확인 권장. 기본은 유지.
- **"지하철 노선도 빼기" 범위** — 신규 코스에만 적용인지, `joseon-kings`의 노선도까지 교체인지 재확인.
- **게임플레이/시각화 분리** — `JourneyPlay`의 입력·판정·`journey-progress` 저장 로직은 UI와 무관하게 재사용해야 코스별 UI가 쉬워짐. 리팩터의 핵심.
- **analytics 이벤트**(`journey_*`)는 그대로 재사용 가능. 리브랜딩해도 이벤트명은 유지(데이터 연속성) 권장.
- **접근성**: 타이핑 대상 텍스트는 실제 DOM 텍스트로 둘 것(SVG 시각화 안에 텍스트만 있으면 크롤/스크린리더 불리).
